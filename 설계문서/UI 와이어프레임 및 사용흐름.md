# Paragraphy UI 와이어프레임 및 사용 흐름

> 실제 구현된 프론트엔드 기준으로 작성된 문서입니다. 이 프로젝트는 하나의 백엔드(`backend/`,
> port 8000)를 **두 개의 프론트엔드**가 공유합니다. 기능(로그인, 문제 선택, 채점, 첨삭, Tutor
> Chat, 답안 기록, 채점 비교)은 완전히 동일하고, 화면 구성(레이아웃)만 다릅니다.
>
> | | 폴더 | 포트 | 특징 |
> |---|---|---|---|
> | UI ① | `frontend/` | 3000 | 왼쪽 사이드바 메뉴 + 오른쪽 결과 패널 pill-tab |
> | UI ② | `frontend-v2/` | 3001 | "원고지 워크스페이스" — 캔버스 중심, 접이식/리사이즈 가능한 좌우 패널, 커맨드 팔레트형 문제 전환 |
>
> `./manage.sh {frontend|frontend2} {start|stop|restart|status}`로 각각 독립 제어합니다.

---

## 1. 공통 백엔드 흐름도

두 UI 모두 아래와 동일한 API 계약(`/api/...`)을 사용하므로, 상태 전이 자체는 같습니다.

```mermaid
flowchart TD
    Start([접속]) --> Landing[랜딩 페이지\n"Paragraphy 시작하기" 버튼]
    Landing --> Login[로그인 오버레이\n식별자 입력]
    Login -->|신규/기존 식별자| PickOrEmpty{문제 선택됨?}

    PickOrEmpty -->|아니오| Picker[문제 선택/직접 입력]
    PickOrEmpty -->|예 - 답안기록에서 복귀| Writing

    Picker -->|기존 문제 클릭| Writing
    Picker -->|직접 입력\n제목+본문 작성| RubricGen{채점기준 있음?}
    RubricGen -->|없음| AIGen[AI로 채점기준 생성\nRubric Agent 호출]
    AIGen --> RubricEdit[생성된 채점기준\n미리보기/수정]
    RubricGen -->|있음| RubricEdit
    RubricEdit -->|이 문제로 저장하고 선택| Writing

    Writing[작성 단계\n문제/지문 + 답안 작성] -->|답안 입력 시작| AutoSession[세션 자동 시작\n버튼 없이도 생성]
    AutoSession --> Writing
    Writing -->|답안 저장 클릭| SaveToast["'답안이 저장되었습니다' 안내"]
    SaveToast --> Writing
    Writing -->|채점 요청 클릭| AutoSave[채점 전 현재 답안 자동 저장\n저장 실패 시 채점 중단]
    AutoSave -->|저장 성공| Loading[채점 중\n로딩 + 경과시간 카운트]
    AutoSave -->|저장 실패| Writing

    Loading -->|성공| Result[채점 결과\n점수/준거별 막대/수정방향성\n"문법과 어휘" 준거는 Bareun 결과로 자동 채점]
    Loading -->|실패| Fail{이전 결과 있음?}
    Fail -->|있음| Result
    Fail -->|없음| Writing

    Result --> Tabs{결과 영역 전환}
    Tabs --> ResultTab[채점 결과]
    Tabs --> ProofTab[첨삭 목록\nBareun 어문규정 + LLM 논리/표현 오류 병합]
    Tabs --> ChatTab[Tutor Chat\n채점 후 예시질문 안내]

    ChatTab -->|질문 전송| Thinking["'Tutor가 생각 중...' 표시\n문구 순환"]
    Thinking --> ChatReply[답변 표시]
    ChatReply --> ChatTab

    Result -->|답안 수정 후 재채점| Loading
    Loading -->|재채점 완료, 2회 이상| Compare[채점 비교표 자동 표시\n총점 증감 ▲▼]
    Compare -->|회차 클릭| Preview[해당 회차 답안 원문을\n읽기 전용으로 미리보기\n저장/채점 버튼 비활성화]
    Preview -->|"현재 답안으로 돌아가기"| Writing

    Result -->|답안 기록| History[지금까지 작성한 모든 답안 목록\n2회 이상 채점한 항목은 회차 비교 요약 함께 표시]
    History -->|항목 클릭| Writing
```

**핵심 규칙 (양쪽 UI 공통)**
- 채점 준거는 출처(대학/국립국어원/사용자입력)와 무관하게 항상 **항목당 1~5점**으로 통일되며, 항상 "문법과 어휘(맞춤법·어법 정확성)" 준거가 포함되고 이 값만은 LLM이 아니라 **Bareun 어문규정 검사 결과 개수로 결정론적으로** 채점됩니다.
- "채점 요청"은 항상 채점 직전에 현재 답안을 먼저 저장합니다. 저장이 실패하면(빈 답안, 네트워크 오류) 채점을 진행하지 않고 중단합니다 — 화면에 보이는 답안과 실제로 채점되는 답안이 어긋나는 것을 막기 위함입니다.
- 채점이 완료될 때마다 `AnalysisResult`에 그 시점의 답안 원문을 스냅샷으로 저장합니다. 채점 비교표에서 회차를 클릭하면 그 스냅샷을 읽기 전용으로 불러옵니다(원문이 없는 아주 오래된 기록은 안내 문구만 표시).

## 2. UI ① 사이드바형 (`frontend/`, port 3000)

### 2-1. 랜딩 · 로그인

```
┌──────────────────────────────────────────┐
│        (다크 네이비 그라데이션 배경)          │
│              [P 로고 배지]                  │
│      대학 채점 기준으로,                     │
│      내 논술 점수를 바로 확인하세요           │
│   대학별 모의논술과 국립국어원 논증적 글쓰기... │
│         [ Paragraphy 시작하기 ]             │
└──────────────────────────────────────────┘
                    │ 클릭
                    ▼
┌──────────────────────────────────────────┐
│   ┌──────────────────────┐               │
│   │ P  Paragraphy         │               │
│   │ 식별자(이름/별명)를     │               │
│   │ 입력하세요.             │               │
│   │ [___________________] │               │
│   │ [      시작하기       ] │               │
│   └──────────────────────┘               │
└──────────────────────────────────────────┘
```
- `localStorage`에 저장된 식별자가 있으면 로그인 화면을 건너뜁니다.

### 2-2. 전체 셸 (로그인 후)

```
┌────────────────────────────────────────────────────────────┐
│ P Paragraphy                     논술 채점 · 첨삭   유진 전환 │  ← 상단바(navy)
├───────────┬────────────────────────────────────────────────┤
│ 문제 선택   │ 선택된 문제가 없습니다.                          │  ← content-info-bar
│ 문제직접입력│                                                │
│ ─────────  │         (선택한 사이드바 메뉴에 따라               │
│ 답안 기록   │          아래 5개 화면 중 하나가 표시됨)            │
│ 채점 비교   │                                                │
└───────────┴────────────────────────────────────────────────┘
```
- 사이드바는 **문제 선택 / 문제 직접 입력 / (구분선) / 답안 기록 / 채점 비교** 4개 항목입니다.
- "채점/첨삭/챗봇"은 사이드바 항목이 아니라, 문제를 선택하거나 답안 기록·채점 비교에서 세션을 열면 진입하는 **작업 화면 안의 상단 pill-tab**입니다 (2-5 참고).

### 2-3. 문제 선택 / 문제 직접 입력

```
문제 선택                                          [문제 새로고침]
기존에 등록된 문제 중 하나를 선택하면 바로 답안 작성으로 이동합니다.
┌──────────────────────────────────────────────────────────┐
│ 국립국어원 논증적 글쓰기 — 로봇세 도입                        │
│ 국립국어원 · 논증적 글쓰기 · 2025                            │
├──────────────────────────────────────────────────────────┤
│ 경희대 사회계 논술 2026 / 2025, 한양대 상경 논술 2026 / 2025   │
│ (카드 전체가 뷰포트 하단까지 늘어나며, 넘치면 내부 스크롤)        │
└──────────────────────────────────────────────────────────┘
```
카드를 클릭하면 즉시 "작업 화면"(2-5)으로 이동합니다.

**문제 직접 입력** 화면도 같은 카드 프레임 안에서:
```
문제 제목        [___________________________]
문제 본문/제시문  [___________________________]  ← flex:1, 남는 세로 공간을 채움
채점 기준(선택)                    [AI로 채점기준 생성]
                 [___________________________]  ← flex:1, AI 생성 결과 미리보기/수정 가능
                 [    이 문제로 저장하고 선택    ]
```
저장하면 그 문제가 자동 선택되어 작업 화면으로 이동합니다.

### 2-4. 답안 기록 / 채점 비교

```
답안 기록                                    채점 비교
지금까지 작성한 답안을 다시 열어...             2회 이상 채점한 문제를 선택하면
                                            "채점" 화면에서 회차별 점수를 비교
┌──────────────────────────────────┐        ┌──────────────────────────────────┐
│ 한양대 상경 논술 2025      19 / 25 │        │ 한양대 상경 논술 2025      19 / 25 │
│ 한양대 · 2026.08.13 12:22 · 채점 2회│       │ 한양대 · 2026.08.13 12:22 · 채점 2회│
├──────────────────────────────────┤        └──────────────────────────────────┘
│ 경희대 사회계 논술 2025    미채점  │        (2회 이상 채점한 항목만 필터링해서 표시)
└──────────────────────────────────┘
```
- **답안 기록**: 답안을 한 번이라도 저장한 모든 세션.
- **채점 비교**: 그중 `attempt_count >= 2`(2회 이상 채점)만 필터링한 목록.
- 두 목록 모두 항목을 클릭하면 해당 세션을 그대로 복원해 작업 화면(2-5)으로 이동합니다 — 이미 2회 이상 채점된 항목이면 재채점 없이도 채점 비교표가 바로 보입니다.

### 2-6. 컴포넌트 재사용 구조 (구현 메모)

`#problemBox`(문제/지문) · `#answerBox`(답안 작성) · `#resultPanel`(pill-tab 3종)은 고정 마크업이며,
`updateWorkLayout()`이 상태(채점 전/후)에 따라 `#leftColumn`/`#rightColumn` 사이로 `appendChild`
이동시킵니다. 답안 textarea의 입력값·스크롤 위치·이벤트 리스너가 화면 전환 중에도 유지됩니다.

## 3. UI ② 원고지 워크스페이스 (`frontend-v2/`, port 3001)

랜딩·로그인 화면은 UI ①과 동일합니다(같은 카피, 같은 로고). 로그인 이후 구조가 완전히 다릅니다.

### 3-1. 전체 셸 — 캔버스 중심 + 접이식 좌우 패널

```
┌────────────────────────────────────────────────────────────────┐
│ 🖋 Paragraphy   [현재 문제: 한양대 상경 논술 2025 ▾]  19/25▲5 🕐 유진 전환│ ← 상단바
├───────┬─┬──────────────────────────────────────┬─┬─────────────┤
│ 문제   │┆│                                      │┆│ [채점결과]   │
│ 제시문 │┆│   (원고지 줄무늬 배경의 답안 작성 캔버스)  │┆│ 첨삭목록     │
│ [채점  │┆│    — 패널 전체 폭을 그대로 사용)          │┆│ Tutor Chat  │
│  기준  │┆│                                      │┆│             │
│  보기] │┆│         [답안 저장] [채점 요청]         │┆│             │
└───────┴─┴──────────────────────────────────────┴─┴─────────────┘
  ▲       ▲                                        ▲       ▲
  좌 패널  리사이즈 핸들(드래그로 폭 조절, 220~552px)  핸들    우 패널(300~520px,
  (기본                                            (드래그) 두 패널을 동시에 늘려도
   360px)                                                   캔버스는 항상 380px+ 확보)
```
- 좌/우 패널 경계의 얇은 세로줄(리사이즈 핸들)을 **드래그**하면 패널 폭이 바뀝니다. 클릭(짧게 누르고 뗌)은 바로 옆의 화살표 버튼이 담당하는 접기/펼치기이고, 실제로 끌었을 때만 크기가 바뀌어 서로 간섭하지 않습니다.
- 폭은 무한정 커지지 않고 각 패널의 min/max 안에서, 그리고 두 패널을 동시에 최대로 늘려도 답안 작성 캔버스가 항상 최소 폭(380px) 이상을 유지하도록 반대쪽 패널 크기까지 함께 고려해 동적으로 제한됩니다.
- 화살표 버튼(토글)을 누르면 해당 패널이 폭 0으로 접혀 캔버스가 그만큼 넓어집니다.
- 상단바의 "현재 문제" 배지를 클릭하면 문제 전환 팝업이, 시계 아이콘을 클릭하면 답안 기록·채점 비교 통합 패널이 열립니다(아래 참고). 채점 완료 상태면 상단바에 점수 칩(예: `19/25`)이 함께 표시됩니다.

### 3-2. 문제 전환 — 커맨드 팔레트형 오버레이

```
┌──────────────────────────────────────────┐
│ 🔍 문제 검색 — 학교, 연도, 키워드...      ✕ │
├──────────────────────────────────────────┤
│ 대학 논술                                  │
│  한양대 상경 논술 2025 ✓  한양대·상경계열·2025│
│  한양대 상경 논술 2026     ...              │
│  경희대 사회계 논술 2025/2026               │
│ 국립국어원                                 │
│  논증적 글쓰기 — 로봇세 도입                 │
│ 내가 만든 문제                             │
│  낙태에 대한 자신의 생각을 논하라             │
│ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄ │
│ [+ 문제와 채점 기준 직접 입력하기]           │
└──────────────────────────────────────────┘
```
- 검색창에 입력하면 실시간으로 목록이 필터링됩니다.
- "문제와 채점 기준 직접 입력하기"를 누르면 같은 팝업 안에서 입력 폼으로 전환됩니다(제목/본문/채점기준 + AI 생성 버튼 + 저장 버튼). "← 목록으로"로 다시 검색 목록으로 돌아갈 수 있습니다.
- 문제를 선택하거나 새로 저장하면 팝업이 닫히고 캔버스에 바로 반영됩니다.

### 3-3. 좌측 문제 패널 / 캔버스 / 우측 결과 패널

```
좌측 패널                          중앙 캔버스                     우측 패널
┌────────────────┐   ┌──────────────────────────────┐   [채점 결과][첨삭목록][Tutor]
│ 한양대 상경 2025 │   │ ▓작성 중▓                71자│   19/25  한양대 채점 기준 적용
│ 한양대·상경계열  │   │┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈│   준거별 점수 막대 (문법과 어휘
│                │   │(나)에서 노나라 왕은 바닷새를…  │    포함, "Bareun 자동" 태그)
│ [문제 본문/지문] │   │┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈│   수정 방향성
│                │   │  (빨간 물결밑줄 = 첨삭 대상)    │   ── 2회 이상 채점 시 ──
│ ▸ 채점 기준 보기 │   │┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈│   채점 비교표(회차 클릭 가능)
│  (펼치면 전문)   │   │        [답안 저장][채점 요청]  │
└────────────────┘   └──────────────────────────────┘
```
- 문제 패널의 "채점 기준 보기"는 별도 팝업이 아니라 `<details>` 접이식 섹션으로, 패널 안에서 바로 펼쳐집니다.
- 답안 작성 캔버스는 은은한 원고지 줄무늬 배경이며, 패널을 아무리 넓혀도(또는 좁혀도) 캔버스가 자기 컨테이너의 전체 폭을 그대로 씁니다.
- 채점 전에는 우측 패널에 "아직 채점 결과가 없습니다" 안내만 보이고, 첨삭/Tutor 탭도 각각 "채점 후 표시됩니다" 상태입니다.
- **채점 비교표 회차 클릭** 시 동작은 UI ①과 동일합니다(좌측 캔버스에 해당 회차 답안을 읽기 전용으로 표시 + "현재 답안으로 돌아가기" 배너).

### 3-4. 답안 기록 · 채점 비교 — 하나로 통합된 슬라이드오버

UI ①과 달리 별도 화면 2개가 아니라, 상단바 시계 아이콘 하나로 열리는 **오른쪽 슬라이드오버 하나**에 전부 들어 있습니다.

```
                                          ┌────────────────────────┐
                                          │ 답안 기록 · 채점 비교  ✕ │
                                          │ 2회 이상 채점한 항목은    │
                                          │ 회차 비교가 함께 보입니다 │
                                          ├────────────────────────┤
                                          │ 한양대 상경 논술 2025    │
                                          │ 한양대·2026.08.13 12:22  19/25│
                                          │ 1회차 14/25 → 2회차 19/25 ▲5│
                                          ├────────────────────────┤
                                          │ 경희대 사회계 논술 2025   │
                                          │ 경희대·2026.08.13 11:47  미채점│
                                          └────────────────────────┘
```
- 2회 이상 채점된 항목은 "1회차 X → 2회차 Y ▲/▼" 요약이 카드 안에 바로 표시됩니다(따로 "채점 비교"로 들어갈 필요 없음).
- 항목을 클릭하면 해당 세션이 복원되어 캔버스에 바로 표시됩니다.

### 3-5. 컴포넌트 구조 (구현 메모)

UI ①과 달리 `appendChild`로 컴포넌트를 이동시키지 않습니다. 문제 패널·캔버스·결과 패널이 각자
고정된 위치(좌/중앙/우)에 항상 마운트되어 있고, 상태에 따라 **보이는 내용과 폭**만 바뀝니다
(`updateCanvasState()`, `renderProblemDrawer()`, `setActiveResultTab()`). 좌우 패널의 접기/펼치기는
CSS 클래스(`workspace.problem-collapsed` / `.drawer-collapsed`)로, 리사이즈는 `panel.style.width`
인라인 스타일로 제어합니다.

## 4. 두 UI를 함께 개발할 때 지켜야 할 것

- 백엔드 API 계약이 바뀌면 **`frontend/app.js`와 `frontend-v2/app.js` 양쪽 모두**에 반영합니다. 두 프론트엔드는 공유 모듈이 없는 완전히 독립된 정적 파일이라, 한쪽만 고치면 다른 쪽이 조용히 뒤처집니다.
- 새 백엔드 기능을 추가할 때는 이 문서의 "1. 공통 백엔드 흐름도"를 먼저 갱신한 뒤, 두 UI 섹션에 각자의 화면 표현을 추가하는 순서를 권장합니다.
