1. 유저 등록 / 로그인
```mermaid
sequenceDiagram
    participant User
    participant Frontend
    participant API server
    participant User DB
    Frontend->>User: 식별자 입력 요청
    User->>Frontend: 식별자 입력
    Frontend->>API server: 식별자 전송
    API server->>User DB: 식별자 질의
    opt 식별자 비존재시
    User DB->>User DB: 새 entry 생성
    end
    User DB->>API server: 존재 여부 확인 신호
    API server->>Frontend: 로그인 완료 신호
    Note over Frontend: 식별자를 기본 토큰으로 이용
    
```

2. 문제 생성 요청
```mermaid
sequenceDiagram
    participant User
    participant Frontend
    participant API server
    participant 문제 DB
    participant Logging DB
    Frontend->>API server:문제 목록 요청
    API server->>문제 DB:문제 목록 요청
    문제 DB->>API server: 문제 목록
    API server->>Frontend: 문제 목록
    Frontend->>User:문제 목록 표시
    User->>Frontend:문제 요청
    Frontend->>API server:문제 요청 (문제 종류)
    API server->>문제 DB: Query
    문제 DB->>API server: 문제, 인덱스
    API server->>Logging DB: 새 항목 생성 (유저 생성자, 문제 인덱스)
    Logging DB->>API server: 새 항목 세션 식별자
    API server->>Frontend: 문제, 인덱스, 세션 식별자
    Frontend->>User: 문제
```
3. 채점 요청
```mermaid
sequenceDiagram
    participant User
    participant Frontend
    participant API server
    participant 문제 DB
    participant Agent
    participant Logging DB
    User->>Frontend: 채점 요청
    Frontend->>API server: 문제 인덱스, 유저 답안, 유저 식별자, 세션 식별자
    API server->>문제 DB: 인덱스
    문제 DB->>API server: 채점 기준, 모범 답안
    API server->>Agent: 채점 기준, 유저 답안, 모범 답안
    Agent->>API server: 어/문법 오류 목록, 점수, 근거, 개선 방향
    API server->>Frontend:  어/문법 오류 목록, 점수, 개선 방향
    API server->>Logging DB: 세션 식별자, 유저 답안, 어/문법 오류 목록, 점수, 근거, 개선 방향
    Note over Logging DB: 세션 식별자를 이용해 기존에 만든 세션에 내용 추가
    Frontend->>User: 어/문법 오류 목록, 점수, 개선 방향
```

4. 과거 세션 불러오기
```mermaid
sequenceDiagram
    participant User
    participant Frontend
    participant API server
    participant Logging DB
    Frontend->>API server: 유저의 과거 첨삭 요청 (유저 식별자)
    API server->>Logging DB: 식별자를 이용한 질의
    Logging DB->>API server: 해당 식별자의 첨삭 목록 (세션 이름?)
    API server->>Frontend: 첨삭 목록 전송 (세션 이름/세션 식별자)
    Frontend->>User: 첨삭 목록 보여주기
    User->>Frontend: 세션 선택
    Frontend->>API server: 선택된 세션 식별자 전송
    API server->>Logging DB: 세션 식별자로 첨삭 선택
    Logging DB->>API server: 유저 답안, 어/문법 오류 목록, 점수, 개선 방향
    API server->>Frontend: 유저 답안, 어/문법 오류 목록, 점수, 개선 방향
    Note over Frontend, User: API server에서 받은 내용을 기반으로 보여주기
```

5. 채팅
```mermaid
sequenceDiagram
    participant User
    participant Frontend
    participant API server
    participant 문제 DB
    participant Chatting Agent
    participant Logging DB
    User->>Frontend: 채팅 입력
    Frontend->>API server: 채팅 내용 전달
    API server->>Chatting Agent: 채팅 입력, 세션 식별자
    opt Tool Calling - 첨삭
    Chatting Agent->>Logging DB: 세션 식별자로 [유저 답안, 점수, 개선 방향, 근거] 중 필요 항목 요청
    Logging DB->>Chatting Agent: 요청 항목
    end
    opt Tool Calling - 문제
    Chatting Agent->>Logging DB: 세션 식별자로 문제 인덱스 요청
    Logging DB->>Chatting Agent: 문제 인덱스
    Chatting Agent->>문제 DB: 문제 인덱스로 모범 답안 요청
    문제 DB->>Chatting Agent: 모범 답안
    end
    Chatting Agent->>API server: 채팅 답변
    API server->>Frontend: 채팅 답변
```
